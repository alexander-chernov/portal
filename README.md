# Portal — городской портал

Legacy PHP-приложение для регионального портала. Объединяет сервисы недвижимости, частных объявлений, поиска работы, каталога организаций и публикаций о городе.

## Возможности

- Недвижимость: продажа и аренда, поиск, карточки объектов, адреса и карта.
- Фото-объявления, вакансии и резюме.
- Каталог организаций с общим поиском.
- Блог о достопримечательностях Томска.
- Личные кабинеты пользователей, агентов по недвижимости и экспертов.
- Административная панель с модерацией контента, управлением пользователями, рубриками, тарифами и баннерами.

## Технологии

- PHP (классический монолит без Composer)
- MySQL
- HTML/CSS и jQuery
- PHPMailer для почтовых уведомлений
- TinyMCE в административной панели
- API Яндекс Карт и 2ГИС для геокодирования

## Развёртывание

Сборка не требуется. Для работы необходимы веб-сервер с PHP и MySQL.

1. Разместите проект в document root веб-сервера.
2. Импортируйте базу данных `kedr`. SQL-дамп в репозиторий не включён.
3. Настройте параметры подключения и домен в `admin/inc/configs.php`.
4. Настройте SMTP-параметры для почтовых уведомлений.
5. Выдайте веб-серверу права на запись в каталоги, используемые загрузчиками файлов.

Для локального просмотра при установленном PHP можно использовать встроенный сервер:

```bash
php -S localhost:8080
```

## Ограничения

Проект создан в 2013 году и использует устаревшие PHP-подходы, в том числе вызовы `mysql_*` в части модулей. Перед запуском на современной версии PHP потребуется проверить совместимость и, при необходимости, обновить слой работы с базой данных.

В репозитории отсутствуют SQL-схема, контейнеризация, автотесты и модуль интерактивной карты, который ожидается как внешний компонент.
